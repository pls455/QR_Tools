# Minhaj | منهاج

نسخة منظمة من منصة منهاج التعليمية، مبنية على HTML/CSS/JavaScript مع Firebase وFirestore وخدمات Cloudflare/Apps Script.

## الهدف

هذا المستودع هو النسخة الجديدة المنظمة للمشروع. تم تنظيف ملفات QR القديمة منه، وسيتم نقل مشروع Minhaj بعد مراجعته بدل الاستمرار في إنشاء نسخ متفرقة.

## التقنية الحالية

- HTML + CSS + JavaScript Modules
- Firebase Authentication
- Cloud Firestore
- Cloudflare Worker
- Google Apps Script
- GitHub Pages

لن يتم تحويل المشروع إلى React أو إطار آخر في هذه المرحلة. بعد استقرار البنية، يمكن نقل JavaScript إلى TypeScript تدريجيًا إذا أثبتت فائدته.

## قواعد العمل

- لا ملفات إصلاح مؤقتة فوق ملفات إصلاح أخرى.
- لا مفاتيح أو أسرار داخل المستودع.
- لا تغيير تقني كبير قبل اختبار السلوك الحالي.
- أي ملف غير مستخدم يتم حذفه بدل إبقائه كعبء تاريخي.
