# Minhaj | منهاج

نسخة منظمة من منصة منهاج التعليمية، مبنية على HTML/CSS/JavaScript مع Firebase وFirestore وخدمات Cloudflare/Apps Script.

## المرحلة الحالية

تم إعداد المستودع ليكون نسخة هندسية مستقلة تعتمد على مصدر Minhaj دون تعديل المستودع الأصلي. سيتم تنفيذ إعادة الهيكلة تدريجيًا مع الحفاظ على السلوك والوظائف الحالية.

## الخطة الهندسية

- تنظيف الملفات القديمة والإصلاحات المؤقتة.
- تقسيم الملفات التي تجمع مسؤوليات كثيرة.
- فصل UI عن الخدمات والبيانات والصلاحيات.
- استخدام TypeScript تدريجيًا عندما تكون فائدته واضحة.
- عدم تحويل المشروع إلى React لمجرد تغيير التقنية.
- اختبار JavaScript والمسارات والمراجع قبل كل مرحلة.

## التقنية

- HTML / CSS / JavaScript Modules
- Firebase Authentication
- Cloud Firestore
- Cloudflare Worker
- Google Apps Script
- GitHub Pages
